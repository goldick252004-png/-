# Рилс «Собираем Шрека» (IMG_5364 + IMG_5365)

Готовое видео: `shrek_reel.mp4` (1080×1920, 30 fps, ~91 с). Субтитры отдельным файлом: `shrek_reel.srt`.

## Что сделано
- Два горизонтальных ролика склеены в вертикальный рилс 9:16 (видео в рамке по центру, размытый фон из самого кадра).
- Вырезаны паузы: речь идёт подряд, между фразами остаётся только короткий «вдох». Речь ускорена на 12 % (тембр не меняется).
- Моменты сборки и тишины — таймлапс ×3…×6 с плашкой «⏩» и мем-подписью.
- Мат вырезан и заменён бипом + вставка «ЦЕНЗУРА» (3 места). Проверено: распознавание итоговой дорожки мата не находит.
- Субтитры по словам (активное слово жёлтое, имена героев зелёные), зум-«панчи», тряска, вспышки.
- Мем-вставки: эмодзи-стикеры, карточки «Ждал Кота в сапогах, а выпал Мерлин», гигантские реакции, конфетти, CTA в конце.
- Звук: синтезированные SFX (вайн-бум, свуш, динг, грустный тромбон, зап, скретч, тада) и фоновая музыка с авто-приглушением под голос. Итог −14 LUFS.

## Пересборка
Скрипты: `reel.py` (сценарий + рендер), `lib.py` (графика), `synth.py` (звук). Правки текста/таймингов — в начале `reel.py` (`ITEMS`, события).

Зависимости: `ffmpeg`, `python3` с `numpy scipy opencv-python-headless pillow cairosvg fonttools`,
эмодзи `@twemoji/svg` (кладутся в `../assets/node_modules/@twemoji/svg`) и шрифты Montserrat Black / Russo One (ttf в папке `fonts/`: `<name>-latin.ttf` и `<name>-cyrillic.ttf`, из npm `@fontsource/*`, woff → ttf через fontTools). Пути исходников видео — в начале `reel.py` (`SRC`).

```
python3 reel.py out.mp4            # полный рендер
python3 reel.py out.mp4 --only 0 150   # только кадры 0–149 (быстрая проверка)
```
